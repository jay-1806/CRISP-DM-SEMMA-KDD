## Methodologies Overview

### 1. CRISP-DM (Cross Industry Standard Process for Data Mining)
**Phases covered:**
- Business Understanding  
- Data Understanding  
- Data Preparation  
- Modeling  
- Evaluation  
- Deployment  

**Tools:** Python, Pandas, Scikit-learn, Seaborn, Google Colab

### 2. SEMMA (Sample, Explore, Modify, Model, Assess)
**Phases covered:**
- Sample – Data extraction and initial analysis  
- Explore – Descriptive and correlation analysis  
- Modify – Feature engineering and variable transformations  
- Model – Predictive modeling using SAS / Python  
- Assess – Model validation and evaluation  

**Tools:** SAS (trial version) and Python alternatives
Each stage verified through ChatGPT/GPT-5 critiques for completeness and accuracy.

**Phases covered:**
- Selection  
- Pre-processing  
- Transformation  
- Data Mining  
- Interpretation / Evaluation  

**Tools:** Python, Pandas, Matplotlib, AutoML (optional)
